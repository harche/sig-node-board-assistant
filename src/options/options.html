SIG Node Board Assistant

Jev's read of every card in the Triage column, on the board itself. You decide what happens next.

GitHub read-only token

Create one at github.com/settings/personal-access-tokens with resource owner kubernetes, organization permission Projects: read and access to public repositories. The extension only sends GET requests, so a read-only token is all it can use.

TypeSafe Jev decision model

From typesafe.ai. Judging one card costs about $0.0002 and the answer is cached, so revisiting the board is free.

Model

What it does

  • Reads the Triage column, each item's thread and changed files
  • Asks Jev four calibrated questions and applies the board's written policy
  • Shows the verdict on the card and the evidence in a drawer
  • Never comments, labels, or moves a card. There is no write path in the code.
